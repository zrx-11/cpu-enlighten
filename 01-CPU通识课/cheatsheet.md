# 速查表

考前、面试前、读新闻前扫一眼。数字都取自原书，括号里是出处章节。

## 公式与规则

| 场景 | 内容 |
|---|---|
| 性能估算 | 性能 ≈ 主频 × 每拍执行指令数（IPC）× 并行度 |
| 多核加速上限 | Amdahl：S = 1 / ((1 - a) + a / n)，a 为可并行比例，n 为核数 |
| 单核加速的封顶 | 串行部分占比 1-a，则加速比上限为 1/(1-a) |
| MIPS 的用法 | 只在同架构内比较；跨架构无意义（指令含金量不同） |
| 流水线吞吐 | k 级流水执行 m 条指令，理想拍数 ≈ k + (m - 1) |
| 制造成本 | 成本 =（晶片 + 测试 + 封装）/ 成品率 |
| 晶片成本 | 与 die 面积成正比；面积减半，单颗晶片成本约减半 |
| 功耗构成 | 动态功耗 ∝ 电容 × 电压² × 频率；另有静态漏电功耗 |
| 纳米工艺 | 指标称栅极沟道最小宽度，不是晶体管整体尺寸 |
| 服务器核数换算 | 单机 2 路 × 4 核 = 8 核；4 路 × 4 核 = 16 核（以 3B4000 为例） |

## 易混对照

| 别混 | 区别 |
|---|---|
| 指令集 vs 微结构 | 前者是规范（一对多），后者是实现方案 |
| CISC vs RISC | 指令复杂度取向；现代 CISC 内部拆成类 RISC 微操作 |
| 软 IP vs 硬 IP | 前者是 HDL 功能描述，后者是含布局布线的版图 |
| 后门 vs 漏洞 | 前者是有意安排（态度问题），后者是疏忽（能力问题） |
| 库函数 vs 系统调用 | 前者在用户态，后者要切内核态；printf 内部可能调 write |
| 虚拟内存 vs 虚拟机 | 前者是地址空间抽象，后者是整机模拟 |
| 流水线 vs 多核 | 前者是单核内并行，后者是核间并行 |
| 乱序执行 vs 多发射 | 前者调顺序，后者调宽度，常一起用 |
| 成品率 vs 良率宣传 | 成品率是制造端良品比例，与设计无关 |
| 生态 vs 软件数量 | 生态还含标准、认证、人才、社区、书籍 |

## 流程步骤

**一条指令的旅程**：取指 → 译码 → 取操作数 → 执行 → 访存 → 写回。

**从代码到芯片**：Verilog → 逻辑综合 → 门级网表 → 布局布线 → GDS2 版图 → 流片 → 晶圆 → 切割 → 封装 → 测试。

**从沙子到芯片**：二氧化硅 → 熔炼提纯（EGS）→ 硅锭 → 切片（晶圆）→ 光刻/注入/蚀刻逐层加工 → 切割成 die → 封装 → 测试。

**验证三档**：模拟器（纯软件、最省、最慢但好调）→ FPGA（买板子、慢约 40 倍）→ 流片（最真、最贵）。

**系统调用一次**：应用调库函数 → 库函数执行 syscall 指令 → CPU 切内核态 → 内核按调用号分发 → 服务例程执行 → 返回用户态。

**生态建设六支柱**：标准规范 → 开源软件 → 解决方案 → 产品认证 → 人才培养 → 书籍出版。
