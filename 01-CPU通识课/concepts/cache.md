# 缓存与存储层次

- **难度**：进阶 | **涉及章节**：第 17 章

## 一句话定义
缓存是放在 CPU 旁边的小而快的存储器，用来兜住"内存太慢"这个事实。

## 为什么重要
CPU 一拍能算完，内存要几十上百拍才给数据。不解决这个落差，流水线再宽也白搭。**存储层次是整个计算机体系里最贵的妥协**。

## 图示
```mermaid
flowchart LR
  R[寄存器<br/>1 拍] --> L1[L1 缓存<br/>几拍]
  L1 --> L2[L2 缓存<br/>十几拍]
  L2 --> L3[L3 缓存<br/>几十拍]
  L3 --> M[内存<br/>上百拍]
  M --> D[磁盘 / 网络<br/>更慢]
```
看图说明：越往右越大越慢。看这张图要抓住"每往下一层，容量涨一个量级，速度掉一个量级"。

## 详解
缓存能起作用，靠的是局部性：时间局部性（刚用过的还会再用）、空间局部性（用了这个地址，附近的也会用）。程序不是随机访问内存的，这让小缓存能拦住大部分访问。

多级缓存之外还有两个关键机制：虚拟内存把物理内存切成页，给每个进程一套独立地址空间；TLB 缓存"虚拟地址到物理地址"的映射，避免每次访存都走一遍页表。

写策略也分两种：写穿（同时写缓存和内存，简单但慢）、写回（只写缓存，标记脏，换出时再写回，快但要维护一致性）。

## 常见误解
- 别以为缓存越大越好。大了变慢、变贵、费电，命中率提升却递减。
- 别以为虚拟内存是"硬盘当内存"。它是地址空间的抽象，换页只是它的一个副作用。
