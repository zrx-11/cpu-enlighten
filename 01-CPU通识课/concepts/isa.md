# 指令集（ISA）

- **难度**：基础 | **涉及章节**：第 4、5、6、37 章

## 一句话定义
指令集是 CPU 能听懂的全部指令的集合，规定每条指令的二进制编码格式，是软件与硬件之间的合同。

## 为什么重要
它是全书的地基。上面接着汇编语言、编译器、操作系统、应用软件；下面接着微结构、电路、工艺。**一种指令集承载一个软件生态**，所以它不只是技术规范，也是产业主权的边界。

## 详解
指令集回答三件事：有哪些指令、每条指令什么编码、操作哪些寄存器与地址。

按复杂度分两派。CISC（复杂指令集）追求一条指令干更多事，x86 是代表；RISC（精简指令集）只留高频简单指令，把复杂操作拆成多条，MIPS、ARM、RISC-V、LoongArch 都属于这派。现代 CPU 的实际做法是：对外呈现 CISC，内部译成类 RISC 的微操作，两派的界限早已模糊。

兼容性是关键属性。同一指令集的不同 CPU 互为"兼容机"，一个程序能在所有兼容 CPU 上跑；不同指令集之间只能靠二进制翻译或重新编译。

## 常见误解
- 别以为指令集是软件。它是规范文档，但由硬件实现，改一处要动整条软硬件链。
- 别以为指令多就强。二八原则下，少数指令承担绝大多数执行次数，多出来的指令常常只占面积。
