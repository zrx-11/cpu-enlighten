# CPU 通识课 · 点化学习系统

把靳国杰、张戈的《CPU 通识课》（310 页）做成了一套能从头学下来的知识库：38 章零基础精讲、8 篇跨章概念页、148 道带解析的自测题、223 张抽认卡、193 条术语，外加一个单文件交互页面和一份可直接部署的静态站点。

打开 `index.html` 就能开始学，不需要装任何东西，也不需要联网（Mermaid 图示联网时才会渲染成图形，离线会显示源码和文字说明）。

## 为什么做成这个样子

原书是「篇 + 第 N 节」的两级结构，47 节里有些一节只有两三页，照原样切会切出一堆半页的碎章。这里按主题把相邻小节并成章，篇内合并、跨篇不合并，最后落到 38 章。合并的原则只有一条：一章必须能独立回答一个问题，并且末尾的自测题能验证这个问题学会了没有。

每章的结构是固定的，但不是模板腔：

- 开头一行元信息（难度、学时、前置），方便你决定要不要现在读；
- 学习目标写成「学完你能……」，跟自测题一一对应；
- 一句话核心，先给结论再展开；
- 零基础讲解按概念切小节，每个概念走「白话定义 → 类比或实例 → 结论」，不跳步；
- 一张 Mermaid 图，紧跟一段「看图说明」，告诉你该看什么、能得出什么；
- 类比与实例，类比都标了失效边界，实例尽量带具体数字；
- 常见误解，用「别以为……实际上……」的句式，每章三条；
- 自测题带答案与解析，抽认卡、术语、复习锚点各就各位。

## 三种用法

**从头学**。打开 `index.html`，左侧「学习路径」有八步，按篇推进：概览 → 术语 → 原理 → 系统 → 生产制造 → 家族 → 生态 → 中国 CPU。每步做完该篇自测题再往下走，全程约 20 小时。原理篇最硬，卡住可以先跳到系统篇找整体感，回头再补；但流水线和缓存两章别跳。

**查着用**。搜索框搜「TLB」「Amdahl」「成品率」这类词，能直接命中章节。或者进术语表按章节筛。写材料、做汇报时最好用。

**复习用**。只看 `cheatsheet.md` 和 `flashcards.md`。前者是公式和数字，后者是记忆钩子。考前两小时翻一遍，比重新读一遍书划算。

## 部署到 GitHub Pages

静态站点，没有构建步骤，也没有后端。

1. 新建仓库，把本目录**里面的内容**推到根目录（不是把整个文件夹塞进去）：

   ```bash
   cd CPU通识课-点化学习系统
   git init
   git add .
   git commit -m "CPU 通识课点化学习系统"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/<仓库名>.git
   git push -u origin main
   ```

2. 仓库 Settings → Pages → Build and deployment → Source 选 `Deploy from a branch`，Branch 选 `main`，目录选 `/ (root)`，保存。

3. 等一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`。

几个容易踩的点：

- `.nojekyll` 必须在根目录。少了它，GitHub 会走 Jekyll 处理，带下划线开头的目录（`_build`、`_work`）会被忽略，页面里的相对链接可能 404。
- 所有链接都是相对路径，放在仓库根目录或子路径（`/repo-name/`）都能用，但别把这个目录再套一层文件夹，否则入口会变成 `/repo-name/CPU通识课-点化学习系统/index.html`。
- 打开后如果只看到空白，先看浏览器控制台。最常见的原因是直接双击了 `01-CPU通识课/cpu-tongshi-companion.html` 却断网——单书伴侣的 Mermaid 要联网才会画图，正文本身不受影响。
- Pages 对大小写敏感。文件名里 `c27-banTu-chengben.md` 有大写 `T`，改名前先确认引用它的地方一起改，或者干脆别改。

## 重新生成

改了章节 Markdown 之后，重跑三步就行：

```bash
# 1. 重新解析章节，抽出题目、卡片、术语
python3 _build/parse_chapters.py

# 2. 重写 manifest.json
python3 _build/make_manifest.py

# 3. 重新组装页面
python3 <book-enlighten 技能目录>/scripts/build_companion.py \
  --manifest 01-CPU通识课/manifest.json \
  --out 01-CPU通识课/cpu-tongshi-companion.html

python3 <book-enlighten 技能目录>/scripts/build_handbook.py \
  --root . --out index.html
```

`parse_chapters.py` 依赖章内格式：自测题必须写成 `1. 题干？｜选项A｜选项B｜选项C｜答案：A｜解析：……`，抽认卡写成 `- 正面？｜背面`，术语写成 `- 术语：白话定义`。改格式要同步改解析脚本，否则 manifest 里会缺题。

## 一点说明

书里的数字、型号、年份、人名都取自原文，章节里的引文也尽量保持原样，方便回查。我在正文里加的是解释、类比、图示和练习题，没有替作者做新的论断。凡是作者明确表达的判断（比如「Intel 赢在生态不在性能」「日本输在只做产品不做标准」），我都标了出处章节，方便你自己回去核对。
